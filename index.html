❤️ Heart Disease Risk Prediction API

Service is running.

This API predicts whether a patient is at risk of heart disease based on clinical parameters, using a Random Forest model trained on the Heart Disease Prediction dataset.

POST /predict

Send patient details as JSON:

{
  "age": 63, "sex": 1, "cp": 3, "trestbps": 145, "chol": 233,
  "fbs": 1, "restecg": 0, "thalach": 150, "exang": 0,
  "oldpeak": 2.3, "slope": 0, "ca": 0, "thal": 1
}

Example response:

{
  "prediction": "Heart Disease Detected",
  "probability": 0.87
}

GET /health

Returns {"status": "ok"} — useful for uptime checks.
